## 🌟 Highlights & Features

- **🍽️ Interactive Degustation Menu**: Browse seasonal menus categorized by Royal Indian Fare, Mains & Woodfire, Small Plates, Cocktails & Wine, and Artisanal Desserts with rich photography and curated descriptions.
- **🔥 Atmospheric Storytelling**: Unveils the culinary philosophy of slow charcoal fire, clay tandoors, and hand-roasted spices from Kerala and Kashmir.
- **🕯️ Dining Spaces Showcase**: Explore dedicated venue spaces including The Candlelit Hearth Room, Live Tandoor Counter, Courtyard Terrace, and the subterranean Sommelier Cellar.
- **📋 Table Reservation System**: Streamlined reservation booking flow capturing seating time, party size, date, guest details, and email confirmation.
- **🎨 Custom Themed Scrollbar**: Custom cross-browser scrollbar seamlessly tuned to the warm terracotta ember (`#D97745`) and charcoal hearth (`#11100E`) design system.
- **⚡ Next.js 16 & React 19 Ready**: Optimized with Turbopack, App Router, responsive Next.js Image components, and zero lint warnings.
- **📱 Fully Responsive**: Fluid typography, responsive layouts, and smooth motion transitions powered by Framer Motion.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18.18 or later) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/thanojsriman/restaurant.git
   cd restaurant
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**
   Open [http://localhost:3000](http://localhost:3000) in your web browser.
